# excel-to-md

Excel ファイルを Markdown に変換するツールです。  
A tool for converting Excel files into Markdown-friendly formats.

## 概要

この README は、このリポジトリの役割を示すための最小 README です。
詳細な使い方、設計、運用ルールが必要な場合は今後追加します。

## 用語としての用例

「excel-to-md で管理会計 PL の階層を Markdown の表に移す」のように、Excel 帳票の内容をテキストとして再利用する変換処理を指します。対象例は列をずらして階層を表す損益計算書、予算表、クロス集計、矢印をセルに置いた業務フローです。

## 思想的背景

[仕様書](docs/excel-to-md-spec.md) の方針は「値・階層・意味を保持し、レイアウトの再現は二次的」です。見た目を完全複製するよりも、読み直しや後処理に使える情報を残します。図形の意味や数式ロジックを完全復元するものではありません。

## 技術的背景と現在の状態

[excel-to-md.py](excel-to-md.py) に Python / openpyxl を用いた変換コードが置かれています。セル結合、太字、空行、罫線、列オフセットなどからセクションや表を捉え、Markdown または JSON を出力する設計です。JSON は整形済みの sections と元構造を残す raw を持ちます。

ただし、現在のファイルにはスマートクォート、Markdown のコードフェンス、インデントの欠落が含まれており、そのまま実行できる Python スクリプトとしては未整備です。仕様書中のファイル名 excel_to_md.py と実ファイル名 excel-to-md.py も異なります。仕様上の用例を実行可能性の保証として扱わないでください。

詳細は [仕様書の使い方・制約・後処理例](docs/excel-to-md-spec.md) を参照してください。利用に進む前に、ソースの構文とファイル名を整え、入力サンプルに対する実行検証が必要です。画像・グラフ、条件付き書式、複雑な結合、数式の扱いには制約があり、元の Excel との照合を前提にしてください。この README 更新ではコードの修正や動作検証は行っていません。
